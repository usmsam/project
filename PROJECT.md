# project

## Суть
Небольшой учебный проект на Create React App: отработка базовой структуры React-приложения и управления состоянием через Context API без внешнего стейт-менеджера.

## Стек
- **Create React App** (`react-scripts`), JavaScript.
- **Состояние:** React **Context API** (`components/Context`).
- **UI:** `react-icons`; тесты — `@testing-library/*`.

## Архитектура
- `src/components/Context/Context.js` — провайдер глобального состояния.
- `src/components/*` — UI-компоненты, читающие контекст.
- `src/App.js` — композиция.

## Фичи
- **Глобальное состояние через Context:** общий стейт без Redux.
- **Компонентная структура** с иконками.

## Сложные места
- **Context API как стейт-менеджер.** Понимание, когда контекста достаточно и где начинаются его ограничения (ре-рендеры) — база перед переходом на Redux/zustand.

## Кейсы
- **«Состояние на Context без Redux».** Границы применимости Context API.
- **Статус: до ИИ.**
- *Примечание: учебный проект.*
